Isaac Save Viewer

A tool to track completion status for
The Binding of Isaac: Repentance+

Hint: The default location on Windows (Steam) is:

C:\Program Files (x86)\Steam\userdata\[Your Steam ID]\250900\remote\rep+persistentgamedata1.dat

On Linux (Steam with Proton), it is:

~/.local/share/Steam/userdata/[Your Steam ID]/250900/remote/rep+persistentgamedata1.dat
